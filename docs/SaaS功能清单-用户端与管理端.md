# 产品功能说明

本文档介绍平台已上线能力，可直接提供给客户与使用方。平台用于 **AI 影视与短剧生产**：将小说、剧本或一句话创意纳入标准化流程，完成剧集拆解、人物 / 场景 / 道具提取、参考图生成、分镜与视频合成，并输出可交付成片。另提供 AI 剧本创作与对话式快速生成，可按项目需要单独使用。

系统按角色进入对应工作台：

- **用户端**：制作工作台。用于剧本创作、资产管理、分镜与成片生产，并查看可用积分。
- **管理端**：运营工作台。用于账号开通、积分充值、模型配置，以及全站进度、消耗与日志查询。制作与运营职责分离，保障生产数据不被运营操作误改。

两端共用登录入口，登录后按角色进入相应工作台。账号由管理端开通并统一发放。

| 端 | 使用对象 | 主要模块 | 权限范围 |
|---|---|---|---|
| 用户端 | 编剧、制片、制作人员 | 总览、作品、剧本创作、速创、资产、流程 | 操作本账号作品与资产；查看积分余额 |
| 管理端 | 运营、客服、财务 | 运营总览、剧本记录、任务记录、用户、物价表、模型、AI 日志、操作日志、积分统计 | 开户、充值、模型配置、全站查询与审计 |
| 登录 | 两端共用 | 账号密码认证 | 登录后进入对应工作台 |

## 一、用户端

覆盖从创意到成片的制作闭环。主路径：新建作品 → 剧集拆解 → 分集出图与出视频 → 导出成片。亦可单独使用 AI 剧本创作，或以对话方式进行单次出图 / 出视频。

### 1. 账号与工作台

提供登录认证、会话管理与积分展示，作为制作入口与用量可见性的基础。

| 序号 | 功能点 | 功能说明 |
|---|---|---|
| U-1.1 | 账号密码登录 | 使用已开通账号进入制作工作台。 |
| U-1.2 | 访问令牌 | 可复制或刷新当前访问令牌，供外部协作系统（如剧本评分、任务对接）以本账号身份读取剧本或创建任务，无需共享登录密码。 |
| U-1.3 | 账号信息与积分余额 | 侧栏展示当前账号、角色及可用积分；生成成功后自动更新余额。 |
| U-1.4 | 退出登录 | 结束当前会话，保障共用设备时的账号安全。 |
| U-1.5 | 侧栏展开 / 收起 | 在分镜编辑、成片预览时收窄导航，扩大制作区域。 |

### 2. 总览

制作首页。汇总本账号作品规模与任务状态，并提供进入各制作模块的入口。

| 序号 | 功能点 | 功能说明 |
|---|---|---|
| U-2.1 | 工作空间指标 | 展示本账号作品数量、可用流程模板、已接入模型及累计剧集。 |
| U-2.2 | 最近作品 | 列出近期项目及完成进度，状态包括计划中、解析中、制作中、已完成、有失败，可进入对应作品继续制作。 |
| U-2.3 | 最近流程任务 | 展示拆解、出图、出视频等任务的当前节点与进度，便于跟进与处理异常。 |
| U-2.4 | 快捷入口 | 从总览进入「新建作品」或流程库。 |

### 3. 作品生产（短剧 / 宣传片）

核心生产模块。一部作品对应一部短剧或一条宣传片。选择输入方式后，系统先完成可拍摄剧集的拆解，再进入分集制作。

| 序号 | 功能点 | 功能说明 |
|---|---|---|
| U-3.1 | 作品库 | 以封面与完成集数展示本账号全部项目，便于检索与继续制作。 |
| U-3.2 | 新建作品 | 创建新项目：选择生产流程（官方或自定义），提交故事素材后按该流程执行。 |
| U-3.3 | 完整小说 / 剧本导入 | 适用于已有长文本或成稿。支持粘贴正文或导入文件，由系统完成结构拆解与分集。 |
| U-3.4 | 一句话创意 | 适用于仅有故事概念、尚无正文的场景。系统先扩写为完整剧本，再分集并进入制作。 |
| U-3.5 | 宣传片 | 适用于 15–60 秒品牌或产品短片。将一句话创意拆为 1–4 段（每段约 15 秒），按宣传片分镜生产。 |
| U-3.6 | 目标集数 | 可指定目标集数；未指定时按剧情体量自动划分。 |
| U-3.7 | 画风大类 | 设定整部作品视觉类型：真人写实、二次元动漫或 3D 渲染。后续图像与视频生成均遵循该设定。 |
| U-3.8 | 画风细分 | 在大类下选择具体质感。写实含电影感、短剧、纪实、商业广告、暗调悬疑；动漫含昭和、平成、萌系、京都动画、新海诚、国漫等；3D 含动画电影、虚幻写实、黏土、低多边形等。 |
| U-3.9 | 内容区域 | 选择国内或海外，用于匹配拆解策略与文案语言（如海外项目保留英文专有名词）。 |
| U-3.10 | 官方流程 | 平台预置的标准生产线，覆盖短剧与宣传片常见场景，可直接启用。 |
| U-3.11 | 自定义流程 | 使用本账号编排的流程执行该作品，例如调整节点或更换模型。 |
| U-3.12 | 作品编辑 | 调整作品名称、画风与区域定位，后续新生成内容按最新设定执行。 |
| U-3.13 | 删除作品 | 移除不再使用的项目。 |
| U-3.14 | 剧本解析 | 提交素材后由系统完成剧集拆解。可查看进度，支持取消或重新执行。 |
| U-3.15 | 解析结果 | 自动生成各集标题、摘要、可拍摄剧情概要与结尾钩子，作为分镜与视频生成的输入。 |

**官方流程：剧本段**

| 流程 | 适用场景 | 执行步骤 |
|---|---|---|
| 完整剧本 | 已有小说或剧本全文 | 导入正文 → 拆解主线 / 人物 / 场景 → 规划分集概要 → 写入剧集列表 |
| 一句话 → 剧本 | 仅有一句话概念 | 扩写完整剧本 → 结构拆解 → 规划分集 → 写入剧集列表 |

### 4. 剧集工作室

作品完成分集后，按集生成画面与视频。支持整集自动执行，也支持在单步停留，进行分镜修订、更换图像或单镜重新生成。

| 序号 | 功能点 | 功能说明 |
|---|---|---|
| U-4.1 | 剧集目录 | 列出各集及制作状态，切换进入对应集工作台。 |
| U-4.2 | 新增 / 删除剧集 | 手工增补或移除集次。 |
| U-4.3 | 编辑本集剧情 | 修订本集可拍摄剧情并保存，作为本集流程的起点。 |
| U-4.4 | 一键生成此集 | 自剧情连续执行至成片，适用于先产出完整初稿再精修。 |
| U-4.5 | 单步生成 / 重新生成 | 仅执行或重跑当前节点，保留已确认的步骤。 |
| U-4.6 | 取消任务 | 取消自动执行或单个节点任务。 |
| U-4.7 | 精修 / 详情 | 查看当前节点的文本、图像、视频及历史版本，进行针对性修订。 |
| U-4.8 | 资产提取与合并 | 从本集剧情识别人物、场景、道具。已有角色跨集复用，以保持全片形象一致；新增资产自动建档并生成参考图。 |
| U-4.9 | 分镜处理 | 将本集剧情拆为可拍摄镜头（画面、动作、台词、镜头语言），时长跟随剧情节奏。 |
| U-4.10 | 分镜人工编辑 | 直接修订单镜的画面描述、动作与台词。 |
| U-4.11 | 分镜引用资产 | 在分镜中绑定指定人物、场景、道具或造型，后续出图与出视频使用对应参考图。 |
| U-4.12 | 单镜 AI 重写 | 仅重写指定镜头，其余镜头文本保持不变。 |
| U-4.13 | 分镜版本 | 每次重写保留历史版本，可对比后选定当前分镜。 |
| U-4.14 | 镜头首帧图 | 为各镜头生成关键画面，用于验收构图与人物一致性，并作为视频生成的视觉依据。 |
| U-4.15 | 镜头视频 | 按该镜时长（如 8 秒、15 秒）生成视频片段，支持页内预览。 |
| U-4.16 | 单镜重生成视频 | 仅重生成指定片段，可同时修订提示词。 |
| U-4.17 | 视频提示词预览 | 提交生成前预览将发送的提示词，便于核对角色与场景信息。 |
| U-4.18 | 镜头衔接 | 宣传片多段之间以上一段结尾承接下一段开头，提升成片连贯性。 |
| U-4.19 | 成片合成 | 将本集各镜头视频合并为可下载的 MP4。 |
| U-4.20 | 通告单 | 将本集拍摄要素整理为通告单，支持页面预览、下载 HTML 或导出 PDF。 |
| U-4.21 | 资产参考 | 在本集工作区展示人物 / 场景 / 道具参考图，供制作时核对。 |
| U-4.22 | 角色音色 | 人物绑定音色后，剧集视频生成将携带该角色参考音频，用于稳定声线。 |
| U-4.23 | 节点内容修订 | 对某一步的生成结果进行人工修订后，可自下一步继续执行。 |
| U-4.24 | 任务状态与重试 | 展示各节点执行状态与异常信息，并支持重新执行。 |

**剧集段流程**

| 类型 | 适用场景 | 执行步骤 |
|---|---|---|
| 短剧 | 多集连续剧情 | 填写本集剧情 → 提取 / 合并资产并生成参考图 → 拆分镜 → 逐镜生成视频 → 合成 MP4 |
| 宣传片 | 15–60 秒广告或预告 | 填写创意 → 提取品牌 / 产品资产 → 拆 1–4 段分镜 → 生成视频并衔接 → 合成短片 |

### 5. 资产管理

资产指作品中复用的人物、场景与道具。独立建档并生成参考图，用于保证全片角色形象与场景的一致性。

| 序号 | 功能点 | 功能说明 |
|---|---|---|
| U-5.1 | 我的资产 | 按作品筛选并集中维护人物 / 场景 / 道具。 |
| U-5.2 | 资产类型 | 按人物、场景、道具分类管理。 |
| U-5.3 | 新建 / 编辑 / 删除 | 补录、修订或移除资产及其设定、标签。 |
| U-5.4 | 核心参考图 | 为资产指定标准外观，支持 AI 生成、本地上传或使用已有图片地址。 |
| U-5.5 | 图片版本 | 同一资产可保留多张候选图，指定当前使用版本，并支持切换历史版本。 |
| U-5.6 | 人物多视图 | 生成含正面、侧面、背面及面部特写的参考板，供不同机位下保持形象一致。 |
| U-5.7 | 人物造型 | 为同一角色维护多套服装造型，各套独立提示词与参考图。 |
| U-5.8 | 补充视图 | 补充特写或细节角度。 |
| U-5.9 | 批量生成核心图 | 按资产类型统一附加风格要求与参考图，批量生成核心外观。 |
| U-5.10 | 生图模型 | 在已开通的图片模型中选择使用。 |
| U-5.11 | 生图任务状态 | 查看排队、进行中与完成状态。 |
| U-5.12 | 复制图片链接 | 复制设定图地址，便于对外确认。 |
| U-5.13 | 解析中保护 | 作品处于剧本解析过程中时，限制资产修改，避免与解析结果冲突。 |

### 6. 角色音色

为人物绑定人声样本，在剧集视频生成时保持该角色声线稳定。

| 序号 | 功能点 | 功能说明 |
|---|---|---|
| U-6.1 | 绑定人物 | 每个角色保留一个当前有效音色。 |
| U-6.2 | 上传 | 上传 5–30 秒 WAV / MP3 / M4A 音频作为声音样本（单文件默认不超过 20MB）。 |
| U-6.3 | 格式校验 | 校验音频真实性、时长与格式。 |
| U-6.4 | 试听 / 替换 / 删除 | 上传后试听确认，支持更换或解除绑定。 |
| U-6.5 | 账号隔离 | 音色仅本账号可管理。 |
| U-6.6 | 视频生成携带 | 创建或重新生成视频时，按当前有效音色带入该次任务。 |

### 8. AI 剧本创作

独立的剧本工作室。配置题材、梗概、创作要求及 AI 角色后，系统自动完成：统筹策划 → 导演阐述 → 编剧正文 → 审校定稿。定稿后可导出，并导入「新建作品」进入拍摄流程。

| 序号 | 功能点 | 功能说明 |
|---|---|---|
| U-8.1 | 项目列表 | 展示各剧本项目的当前步骤、状态与评分结果。 |
| U-8.2 | 新建项目 | 填写项目名称、题材、输出语言、区域风格、故事梗概与创作要求。 |
| U-8.3 | AI 角色配置 | 分别配置统筹策划、导演、编剧、审校，并提供全局默认配置。未单独指定的项继承默认配置。 |
| U-8.4 | 角色参数 | 为各角色指定文本模型、系统提示词、任务提示词、温度、最大输出长度，以及启用状态。 |
| U-8.5 | 提示词变量 | 可在提示词中自动填入项目名称、题材、语言、梗概及上一阶段产出等信息。 |
| U-8.6 | 自动创作流程 | 启动后四角色按序执行。各阶段同时产出完整文稿与给下一步的精简交接内容，控制上下文长度。 |
| U-8.7 | 流程控制 | 支持启动、暂停、继续、失败步骤重试与取消。 |
| U-8.8 | 过程查看 | 展示当前执行角色、阶段产出、所用提示词、耗时与状态信息。 |
| U-8.9 | 分集审校 | 正文含集数标记时，按集审校后合并为完整定稿。 |
| U-8.10 | 导出 TXT | 定稿后导出纯文本，可导入「新建作品」进入拆集与成片。 |
| U-8.11 | 导出 PDF | 导出标准信纸规格 PDF，便于对外评审。 |
| U-8.12 | 剧本评分 | 定稿后可进入评分，返回总分、分项、优缺点与修改建议。 |
| U-8.13 | 外部协作令牌 | 可使用登录令牌，或签发仅用于读取剧本与提交评分的专用令牌，并支持更换与停用。 |

| U-11.5 | 制作体检 | 检查缺失内容、失败任务与一致性问题，判断是否可继续生成。 |
| U-11.6 | 进度与资产查询 | 按作品或剧集查询制作进度及资产情况。 |
| U-11.7 | 单镜修订 | 按指令修订指定镜头，确认后再写入。 |
| U-11.8 | 图像任务 | 为指定资产或镜头生成、重绘、重试或取消图像任务。 |
| U-11.9 | 画面一致性核验 | 结合人物参考图，逐镜比对形象是否一致；确认后生成新的分镜版本。 |
| U-11.10 | 视频任务 | 查询、重试或取消指定剧集的视频任务。 |

### 12. 积分

文本、图像、视频生成按用量扣除积分。侧栏展示当前可用余额。

| 序号 | 功能点 | 功能说明 |
|---|---|---|
| U-12.1 | 余额展示 | 侧栏展示当前可用积分；生成成功后自动更新。 |
| U-12.2 | 按用量计费 | 文本按 Token 计费；图像按张数与清晰度计费；视频按秒数与分辨率计费。 |
| U-12.3 | 失败不计费 | 生成失败不扣除积分。 |
| U-12.4 | 余额校验 | 余额不足时无法提交新的生成任务，充值后即可继续。 |

### 13. 外部协作接口

外部系统可以本账号身份对接制作与评分，权限与积分消耗计入该账号。

| 序号 | 功能点 | 功能说明 |
|---|---|---|
| U-13.1 | 制作任务接口 | 外部系统可上传剧本，并创建、查询、批准、恢复或取消制作任务。 |
| U-13.2 | 剧本评分接口 | 外部评分服务可读取项目列表与正文，并回传评分结果。支持登录令牌或专用评分令牌。 |

## 二、管理端

面向运营、客服与财务。用于账号与额度管理、模型配置，以及全站作品进度、任务状态、消耗与日志查询。管理员进入运营工作台，与制作工作台分离。

### 1. 登录与权限

| 序号 | 功能点 | 功能说明 |
|---|---|---|
| A-1.1 | 管理员登录 | 管理员账号登录后进入运营总览。 |
| A-1.2 | 运营权限 | 用户管理、模型配置、全站日志等仅管理员可访问。 |
| A-1.3 | 制作与运营分离 | 管理员使用运营工作台进行开户、配置与查询，不进入制作页执行生产。 |

### 2. 运营总览

运营首页。展示全站规模、当日任务情况，并提供下钻入口。

| 序号 | 功能点 | 功能说明 |
|---|---|---|
| A-2.1 | 全站指标 | 展示用户数、作品数、剧集数与任务总量。 |
| A-2.2 | 当日任务 | 展示今日任务量，以及排队、运行中、失败数量。 |
| A-2.3 | 最近创建的作品 | 查看最新创建的项目及其归属用户与进度。 |
| A-2.4 | 最近流程任务 | 查看最新拆解与成片任务。 |
| A-2.5 | 刷新 | 手动更新统计数据。 |

### 3. 剧本记录

查询全站作品进度，便于跟进交付状态。本模块为只读查看。

| 序号 | 功能点 | 功能说明 |
|---|---|---|
| A-3.1 | 作品列表 | 分页浏览全站项目。 |
| A-3.2 | 按用户筛选 | 查看指定用户名下作品。 |
| A-3.3 | 关键词搜索 | 按作品名称定位。 |
| A-3.4 | 制作进度 | 展示总集数、已完成集与制作中集。 |
| A-3.5 | 最近任务状态 | 展示该作品最近一次流程任务状态。 |
| A-3.6 | 作品状态 | 自动归类为计划中、处理中、制作中、已完成或有失败。 |

### 4. 任务记录

查询单次后台任务的执行状态，便于客服与技术支持定位问题。本模块为只读查看。

| 序号 | 功能点 | 功能说明 |
|---|---|---|
| A-4.1 | 任务列表 | 分页查看全站生产任务。 |
| A-4.2 | 按用户 / 状态筛选 | 按用户或任务状态过滤。 |
| A-4.3 | 关键词检索 | 按作品或任务信息定位。 |
| A-4.4 | 异常信息 | 展示任务失败时的系统说明。 |

### 5. 用户管理

账号开通、角色设置与积分充值。

| 序号 | 功能点 | 功能说明 |
|---|---|---|
| A-5.1 | 用户列表 / 搜索 | 查询账号、显示名称、角色、状态与积分余额。 |
| A-5.2 | 新建用户 | 开立制作或管理账号（账号为字母、数字、下划线或短横线，长度 3–64 位；初始密码不少于 6 位）。 |
| A-5.3 | 角色设置 | 设置为普通用户或管理员。 |
| A-5.4 | 启用 / 停用 | 控制账号是否可以登录。 |
| A-5.5 | 重置密码 | 由管理员为用户设置新密码。 |
| A-5.6 | 积分充值 | 向指定账号增加积分，可填写备注。 |
| A-5.7 | 充值记录 | 充值写入积分流水，便于核对。 |

### 6. 积分物价表

展示现行计价规则，便于说明用量与费用构成。

| 序号 | 功能点 | 功能说明 |
|---|---|---|
| A-6.1 | 积分单位 | 标明积分与人民币换算关系（当前 1 积分 = ¥0.01）。 |
| A-6.2 | 文本计价 | 按模型的输入 / 输出 Token 计费，并设有单次最低扣费。 |
| A-6.3 | 图像计价 | 按清晰度分档、按张计费。 |
| A-6.4 | 视频计价 | 按时长与分辨率计费，支持 480p、720p、1080p。 |

### 7. 积分统计

按时间、用户、模型与类型汇总消耗，用于对账与用量分析。

| 序号 | 功能点 | 功能说明 |
|---|---|---|

| A-7.2 | 按类型统计 | 分别统计文本、图像、视频消耗。 |
| A-7.3 | 分组查看 | 支持按日、用户、模型、类型汇总。 |
| A-7.4 | 条件筛选 | 按用户、类型、日期区间查询。 |

记录对作品、剧集、资产的创建、修改与删除，便于审计与核对。

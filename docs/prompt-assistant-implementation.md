# 提示词助手：第一版实现与接入

日期：2026-10-15。

## 页面与流程

普通用户侧栏新增「提示词」，页面地址为 `/admin/prompts`。沿用当前 UI 的 PageToolbar、Element Plus 控件、深色主题变量和风格选择器；桌面展示会话、需求对话和结果，窄屏切换对话与结果。

用户描述图片或视频需求后，Agent 补问关键缺项，选择一个或组合最多三个内置方法，再生成提示词。用户侧只展示对话、需求摘要、最终提示词、分镜和参考图，不展示方法来源、Skill 库、匹配理由或内部审校报告。支持版本保存、复制、文本导出、保存提示词模板，以及将最终提示词与该版本使用的参考图一起填入速创。

2026-10-16：决策、生成、审校和自动修正共享当前会话的完整历史问答（会话最多 100 条消息），不再只向生成与审校提供摘要，也不再截断为最近 16 条。最新用户选择覆盖旧选择；历史中的看图缓存不会重复注入模型输入。审校使用明确的原图/最终图片编号映射，未选用的素材不会提交给生成模型，无需反复向用户确认编号与排除说明。可依据已有答案修正的问题通过 `repair_instructions` 自动修正一次，再次审校；只有真正缺失的用户事实才补问。仍共用最多六次模型调用，修正不可用时保留已通过程序校验的提示词并明确提示人工核验。

视频新增 `duration_confirmed` 状态。默认 5 秒和缺少该字段的旧会话均视为待确认，未确认前不生成结果，优先在对话中询问时长。用户可在设置中确认，也可在对话中说明秒数；决策只可提交带用户原话依据的 `specifications.duration`，服务端校验原话来源、1-180 秒范围，并更新会话和最终结果规格。助手回复不能作为用户确认；已有时长只能按最新用户要求修改。后续回合沿用已确认时长。

参考图由 AI 根据对话和看图结果选择，并逐张输出 `reference_usage`：图片编号、用途、保留项和修改项。用途不明且影响交付时先补问。后端校验选择范围，将说明以 `@图片N：…` 写入提示词正文，同时按最终附件顺序重新编号正文、说明和分镜。用户上传的所有原图仍保留在对话中，结果与速创只携带 AI 选择的图；复制、导出、模板及单镜头使用均保留这些用途约束。无图时不添加参考图说明。旧结果保留原内容，重新生成后使用新规则。

视频结果可整体带入速创，也可单独带入某个镜头。正文明确写入总时长、画幅和镜头时间轴，例如总长 5 秒的两个镜头为 `0-3秒`、`3-5秒`；单镜头使用自己的时长和从零开始的时间轴，同时将整体描述标为背景约束。复制、导出与模板使用相同时间安排。参考图、画风、目标模型、时长及画幅一起恢复，不会自动提交媒体生成。

速创读取模型配置的时长选项或范围，并受当前适配器边界限制。未配置时沿用普通模型 5/10/15 秒、MiniMax 4-15 秒的选择。带入或切换模型后若当前时长不可选，保留带单位的原值、持续显示警告并禁用生成；后端拒绝不支持的时长，禁止静默延长。用户主动修改时长时，按原镜头比例更新自动生成的时间标题，保留正文编辑和附件；用户已改写时间标题时不覆盖，提示手动核对时间安排。调整时间标题不能替代对动作节奏的人工确认。

确实缺少方法时，Agent 为本次任务创建并使用一个私有候选 Skill。候选默认不参与以后的自动匹配。后端保留两个案例的「无方法 / 有方法」对照验证和管理接口，有改善证据且无关键问题才启用。普通创作页面不呈现这些实现细节。

输入框支持选择、拖入或粘贴参考图，上传与资产引用合计最多六个。上传图片支持 JPG、PNG、WebP，单张不超过 10MB、1200 万像素。图片绑定当前用户并持久保存，历史消息和每个结果版本记录实际使用的图片；移除当前参考图不会改写旧版本。有图时先通过多模态模型读取可见外观，再进行文字决策；无图时只做文字澄清。同一会话中图片和解析模型不变时复用看图结果。防水等级、内部结构和认证不能从外观推断，必须有用户依据；关键缺项和素材要求在交付前通过对话确认，禁止作为一长串待办随结果交付。

## 模型与部署

- 使用现有模型配置，决策模型为 `type=text`，可选用户有权限使用的模型。页面优先选择已配置的 DeepSeek，否则选择默认文本模型。
- 接口支持 OpenAI-compatible Chat Completions。Endpoint 填基础 API 地址，例如 `https://api.deepseek.com`，也接受完整 `/chat/completions` 地址。实际 `model_id` 和 API Key 由管理员在模型配置中填写，不写入前端。
- DeepSeek 使用 JSON mode；非 legacy reasoner 模型附带 `thinking.type=disabled`。其他兼容通道可设置 `options.supports_json_mode=true`；供应商需接受 Chat Completions 协议和当前模型参数。
- 图片理解使用 `type=text` 且 `options.supports_vision=true` 的模型。管理员在模型编辑中打开「支持图片输入」。未指定解析模型时优先使用支持图片输入的当前决策模型；没有可用模型时明确阻止图片解析，不假装已经看图。本地 DeepSeek V4 Flash 配置已启用并实测支持图文输入。图片以 Chat Completions 的 `image_url` 内容段传递，本地图片使用最长边 1600px 的 JPEG 预览数据，保留原图用于速创，不依赖模型访问本地 URL。日志不保存图片 Base64 正文，实际用量按供应商返回值计费。
- 图片、视频目标模型可不指定，生成通用提示词。指定后会读取已配置的 `duration_options`、`min_duration`、`max_duration`、`aspect_ratio_options` 等能力；视频分镜总时长必须等于任务时长，各段满足已知模型限制。
- 数据表见 `database/sql/20261015_prompt_assistant.sql`。服务按现有项目模式执行 `CREATE TABLE IF NOT EXISTS`；生产环境推荐预先运行迁移，让业务数据库账号不需要建表权限。
- 后端需当前项目的 PHP、MySQL、cURL、mbstring、GD 和 Composer 依赖。页面使用当前登录态和用户权限。

本版使用同步 HTTP 请求。单次生成最多六次模型调用，每次最长 100 秒，PHP 执行限额 620 秒，失效运行在 660 秒后允许恢复。生产代理应为本功能设置 `proxy_read_timeout` / `fastcgi_read_timeout` 大于 620 秒，PHP-FPM 的 `request_terminate_timeout` 也需配合。PHP 并发量高时，应改为队列任务和事件推送。

模型请求接入 `AiRequestLog` 和现有积分计费钩子，包括决策、补问、修复、审校及 Skill 对照验证。重复提交同一个已经完成的请求 ID 不会再次调用模型；失败后的主动重试会重新产生文本用量。

看图、决策、提示词生成和审校阶段出现非法 JSON、截断输出或字段校验失败时，各最多修复一次，整轮共用六次调用上限。修复结果重新执行字段白名单、权限和规格校验。提示词已通过校验后，如果审校仍失败、调用预算不足或模型服务不可用，会保留结果并在对话中提示检查未完成，不误标为已检查。审校发现需要用户确认的关键问题时，先补问，不保存半成品结果。看图、决策或生成修复仍失败时，会话保留失败状态供用户重试。

模型调用错误按供应商 HTTP 状态分类显示：401 为 API Key 鉴权失败，402 为供应商账户余额不足，403 为访问被拒绝，404 为模型或接口地址不存在，400/422 为参数兼容问题，429 为限流。用户错误提示不回显供应商原始响应。401 需要管理员在「模型」中更新有效密钥后再重试，重启服务不会改变供应商的鉴权结果。

## 权限与画风

Agent 只输出三类结构化决定：`ask_user`、`generate_prompt`、`create_skill`。服务端检查字段白名单、Skill ID、媒体类型、素材归属、模型访问权限与数量/长度限制。模型没有 Shell、SQL、任意文件、联网、媒体生成或共享发布工具。候选 Skill 作为创作资料注入，不执行其中的代码或工具声明。

每个任务只有一个主画风，分别为写实、二维动漫和三维渲染。风格预设需与主画风匹配，旧的多画风预设会被拒绝。风格规则由后端合成一次；速创使用预设时接收正文，无预设时接收主画风规则和正文，避免丢失画风或重复预设规则。

会话、结果版本和私有 Skill 均按当前用户隔离。验证中的 Skill 不可删除或再次验证，超时验证恢复为候选。编辑结果产生新版本，并标记为手动编辑。

## 内置方法与边界

内置六种方法：通用图片、通用视频、产品图片、产品营销视频、软件服务宣传、多镜头分镜。内容是对固定版本 MIT 开源方法的本地适配，删去外部执行与供应商价格表。目录位于 `app/resources/prompt_skills.json`，来源和许可证位于 `app/resources/prompt_skills.LICENSE.txt`。

Skill 验证和提示词审校验证的是文字质量与约束遵守，不能证明实际图片、视频效果。填入速创只准备提示词和原始参考图，媒体任务由用户点击生成。尚未提供开源仓库自动搜索/下载、任意 Skill 导入、共享 Skill 发布或自动生成媒体功能。
